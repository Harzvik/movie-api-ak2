## Gokflix :))

I dette prosjektet har jeg laget Gokflix med Next.js, React og TypeScript. Nettsiden henter filmdata fra TMDB og lar brukeren søke etter filmer, filtrere på sjanger og se mer informasjon om hver film.

## Getting Started

API nøkkel må skaffes fra TMDB, deretter legge den til i .env.local filen.
For å få tilgang til APIet må du lage en bruker på TMDB, og deretter opprette en API nøkkel.

For å kjøre prosjekte:
npm run dev
:)
